# Lessons

## 2026-11-11 — „kosmiczny” = efektowny, nie „o kosmosie”
- Błąd: makietę „wersja kosmiczna” potraktowałem dosłownie i zbudowałem motyw kosmiczny (gwiazdy, planeta, kometa, logo-planeta).
- Intencja: „kosmiczny” w potocznej polszczyźnie = bardzo efektowny. Tematyka ma pozostać IT / automatyzacja / chmura.
- Reguła: przymiotniki opisujące „wow” (kosmiczny, odjechany, bajeczny) traktuj jako poziom efektowności, nie motyw. Motyw wizualny wyprowadzaj z tematyki strony; przy wątpliwości dopytaj jednym zdaniem.
